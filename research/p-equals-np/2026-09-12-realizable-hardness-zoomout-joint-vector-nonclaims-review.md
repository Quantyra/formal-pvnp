## Actual vector law and failure accounting

VectorAdvice.output returns the tuple's span on linear independence and none on dependence. It does not use the older spanKernel resampling convention for failed tuples. The failure atom equals the counted failureFraction; the successful atom is (1-failureFraction) times the uniform Grassmann mass. Conditional uniformity is asserted only for a <= dim(V), with positive successful mass proved. For a > dim(V) all outputs are none; a=0 has zero failure.

The retained-space failure bound is 2^r/2^J under a <= r <= J. The real quotient correctly represents the potentially negative exponent r-J and does not use truncated natural subtraction. The actual joint score keeps the same deletion draw s inside g(s,Q), scores failure zero, and is compared to the ideal uniform-subspace joint score. For bounded nonnegative g the ideal-minus-actual loss lies in [0,2^r/2^J]. decoder_event_transfer applies that derived bound to the exact ZoomOutJoint favorable/score/rank event, not a different independent marginal experiment.

This is one fixed-length vector tuple law. It may serve as a shared prefix only after a strategy proof establishes that both provers use the same tuple and matching length. No longer shared stream, prefix projection, correlations among different lengths, matching-guess probability, complete prover strategy or successful branch implementation is constructed here. Independent tuple choices by two provers cannot silently replace the single tuple. Dependence is charged once in this comparison; a different strategy-level accounting requires its own justification.
