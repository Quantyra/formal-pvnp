occurrenceCountFn consumes Lookup's existing machine pair of an encoded unary owner table T and unary query owner v. tableClock derives marks(mulC 3(posCount T)) from the actual supplied table, giving exactly 3m slots on a serialized Instance. No size, count or runtime certificate is passed by a caller. countMark performs actual ownerLookup for each candidate occurrence and emits [true] or [] according to ifEqLen against the query. Equality of lengths is justified because Lookup correctness returns replicate(owner.val) true; Fin.ext converts equal unary lengths to owner equality. This must not be generalized to arbitrary compact binary labels, whose equal-length codes can name different owners.

The FP proof composes the actual lookup, selectors, equality-by-length and countOver functions. The final membership theorem is for exactly the same total occurrenceCountFn as occurrenceCountFn_correct. It is not an existential different machine, an assumed runtime field, or a complexity conclusion drawn from output cardinality. countOver itself is the existing listEncFn-based loop followed by removal of list brackets and marks; the loop counts output lengths, and each successful mark has length one.

length_countOver converts the result to the full derived range, then Prefix.slotList_eq_decode and rank_decode identify that range with the actual row-major Slot list. The proof equates the sum with countP and then the filtered occurrenceList length I.size v. It counts every repeated-owner position and every row occurrence; it does not count only distinct variables, original rows, graph neighbors or representative edges. countOver_eq_replicate supplies the complete output bitstring, not merely an equal length. This is distinct from ordinalScan, whose loop stops before the queried occurrence.

The full result is replicate(I.size v) true for every v : Fin N. Unused owners produce [], and m=0 is handled with I.zero_size. The explicit repeatedSource has all three positions owned by zero and an unused owner one, with counts three and zero. The bound <=3m concerns the full emitted count. Exact argument lengths retain v.val: external 2*|T|+2+v and internal 6m+2*|T|+4+v. No N<=poly(m) assumption is made. For the future compact Source route, the finite first-occurrence carrier and table equality are still required to justify small unary owner queries; generic Instance input alone does not provide that join.
