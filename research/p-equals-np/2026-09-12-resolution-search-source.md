## Exact target and established implication

The target is a uniform deterministic algorithm A that, for every unsatisfiable explicit CNF F, outputs an explicit general resolution refutation within p(r(F)+s(F)) steps for one fixed polynomial p. No bound is promised on satisfiable inputs. Use ordinary bit computation and charge input, output and verification. r is literal-occurrence size (handle empty-clause/empty-input degeneracies directly); after variable renaming this is polynomially equivalent to conventional input length. s counts proof lines, allowing weakening and reuse of earlier lines. This is general DAG resolution, not tree-like, regular, or width-restricted resolution.

Atserias--Muller Theorems 1--2 establish the target iff P=NP. Their polynomial reduction G from 3-CNF has constants c,d>0 such that SAT F implies s(G(F))<r(G(F))^c, while UNSAT F implies s(G(F))>2^(r(G(F))^(1/d)); infinity is allowed. Their Theorem 13 uses an explicit time cutoff: run A for its short-case polynomial guarantee and accept precisely when a refutation appears. Large-case proofs cannot be printed before that cutoff. Finitely many exceptional input sizes are decided separately. Validate outputs so unrestricted behavior outside the unsatisfiable promise cannot create false acceptance. [Primary paper, definitions and Theorems 1, 2, 13](https://www.cs.upc.edu/~atserias/papers/automating-resolution-np-hard/automating-resolution-np-hard.pdf).

Converse detail, independently expanded: for unary budget B, the relation “F has a resolution refutation with at most B lines” is in NP. Encode each clause by its signed membership vector over the n original variables and each justification by input index or earlier-line indices and pivot. Its bit length is O(B(n+log B+log(r+2))); verification checks every inference and final empty clause in polynomial time. Under P=NP, double B=1,2,4,... until that relation is true, then recover a witness by polynomially many prefix-existence decisions on the same bounded witness relation. The first successful B is at most 2s, so total time is polynomial in r+s. This is the standard conditional search-to-decision explanation, not an unconditional candidate mechanism. SAT inputs can run forever; the definition does not require recognizing them. A binary B with only log B charged would not justify this NP argument.

Polynomially related bit and line lengths suffice because clauses use only original variables. Extension variables or succinctly encoded proof blocks require a separate proof-system and cost analysis. Shortest proofs may be exponential in input length even if the target is achieved; the SAT consequence uses the reduction's gap, not running the automatizer directly on arbitrary F until it stops.

## Closest positive baseline and prior obstructions

Ben-Sasson--Wigderson give width at most initial width plus O(sqrt(n log s)) for general resolution. Saturating all clauses up to width w costs n^O(w); for 3-CNF this gives n^O(sqrt(n log s)), with full exhaustive search available as a cap. The analogous tree-like guarantee gives quasipolynomial automatization relative to shortest tree proof, which is a different parameter. Width closure and this transformation are known methods, not a newly discovered navigation algorithm. [Original paper](https://people.inf.ethz.ch/emo/SatSem05/Papers/BensassonWidgerson01.pdf).

Ben-Sasson--Nordstrom Corollary 1.2 constructs explicit 6-CNFs of linear size with linear-length, constant-width refutations but minimum clause space Omega(n/log n). Consequently short proof length does not imply polylogarithmic live-clause space, even allowing arbitrary recomputation. This is about maximum clauses simultaneously retained in a valid inference configuration. It does not prohibit a compact description of a large configuration, streaming output with external random access, or a polynomial-space algorithm; those models must be charged separately. [Primary paper](https://jakobnordstrom.se/docs/publications/ShortProofs_FOCS.pdf).

Berkholz Theorem 3 gives an unconditional width-k decision lower bound excluding O(|F|^((k-3)/12)) multitape-Turing time for every fixed k>=15. Theorem 5 gives, for each fixed k>=3, 3-CNFs with O(n) variables and O(n^2) clauses whose minimum-width-k proofs need Omega(n^(k-1)) lines, yet width-(k+1) tree proofs have O(1) lines, with constants depending on k. Thus finding the narrowest proof can be far costlier than finding a short proof. Neither theorem excludes a search algorithm measured in shortest unrestricted proof length. [Primary paper, Theorems 3 and 5](https://arxiv.org/pdf/1204.0775).

Current related-work check: the CCC 2025 paper on tree-like k-DNF resolution continues to distinguish DAG from tree proofs and analyzes conditional hardness near the known quasipolynomial tree-system algorithms. It does not supply polynomial general-resolution automatization. Its discussion also flags randomness in an earlier shallow-refutation construction, so an ETH claim must not silently replace rETH. This limited search is not an exhaustive novelty certification. [CCC 2025 primary paper, sections 1 and 6](https://drops.dagstuhl.de/storage/00lipics/lipics-vol339-ccc2025/html/LIPIcs.CCC.2025.14/LIPIcs.CCC.2025.14.html).

## Author-selected symbolic frontier: additional source check

The author subsequently selected a symbolic clause-family mechanism, superseding the optional width-navigation test above. ZDD symbolic resolution is established prior art: Pan--Vardi section 2.1 describes literal-index ZDD clause sets and multi-resolution, and develops QBF extensions. Thus exact symbolic union/resolution and favorable compression examples cannot alone be claimed as a new proof-search algorithm or a polynomial bound. [Primary paper](https://cs.rice.edu/~vardi/papers/cp042.pdf).

Bova--Slivovsky Theorem 19 supplies a class of read-three monotone 2-CNFs of size O(n) needing 2^Omega(n) OBDD size for every variable ordering, using bounded-degree expanders. This is a lower bound for the Boolean function of satisfying assignments. An author's hitting-set clause-family transfer must identify exactly that characteristic function by a valid restriction or another operation with a proved size bound; existential projection alone is not automatically a cheap OBDD operation. [Primary paper, Theorem 19](https://d-nb.info/1119846765/34).

Elementary model check: a ZDD on N membership variables with S nodes can be converted to an OBDD for the same set-family characteristic function with O(N(S+1)) nodes by expanding skipped-variable edges into tests requiring each skipped variable to be zero, including terminal edges and the root prefix. Hence an all-order exponential OBDD lower bound transfers to such ZDDs. This observation does not identify the author's actual family or establish that its computation is necessary.

Crucial reachability test: the declared algorithm must necessarily materialize the hard family before finding the empty clause on the chosen short-refutation input. A hard full closure, or an irrelevant satisfiable expander component beside an easy contradiction, only refutes an explicit policy that insists on computing that family first. It does not refute early stopping, subsumption, alternate scheduling, or polynomial automatization. No source found here makes that mandatory-frontier conclusion for the author's as-yet-unreviewed policy.
