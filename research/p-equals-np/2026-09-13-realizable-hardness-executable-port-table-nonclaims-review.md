## Permitted claim

One total function tableFn constructs its own linear-in-n unary counter of length 3nD and materializes the actual fixed port-cycle table for n equal to input length. The row rule computes mixed-radix coordinates, emits both the source dart and the actual rotation result, and encodes that pair as a row. The source proves exact ordered-list agreement with FixedPortCycleFamily.table, then exact serialized bitstring equality for the identical function whose FP membership is proved. No caller-supplied clock, output equality, ordering premise or runtime certificate is required.

Canonical order means the exact existing enumeration: vertex slowest, port index next, dart label fastest. It does not mean a canonical encoding for every isomorphic graph. Both endpoints, reverse labels, repeated occurrences, loops and parallel darts remain represented. Equality is literal ordered serialized output, not merely edge-set equality, permutation or equal row count. The upstream tower table used within rotation computation is not substituted for the actual degree-three replacement table output.

The FP proof uses the actual bounded materializer. Its library proof derives the iteration state bound from the row rule's FP output bound and the unary counter length, then applies the bounded-iteration theorem. Thus this is more than a polynomial output estimate, and it does not assume unrestricted iteration is polynomial. The separate explicit wire bound is

    2 + 3nD * (4*(12n + 6D + 26) + 2).

It includes both endpoint pair encodings, each encoded row and the outer list framing. It is quadratic in n for fixed D. No quadratic runtime theorem follows: execution may use a larger polynomial bound.
