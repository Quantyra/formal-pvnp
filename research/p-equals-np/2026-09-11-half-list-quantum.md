# Indexed half lists and quantum price search

2026-09-11, S3074. Informal reviewed construction under [integrity](../../INTEGRITY-CLAIMS.md), with scoped independent reviews below. No code, hardware, experiment, novelty or P-versus-NP claim. The [S3073 theorem](2026-09-11-connected-half-pricing.md) supplies half coverage and the classical packing wrapper. This attempt removes full-list preparation from the input-oracle contract, but distinguishes quantum queries from fast quantum-memory operations and ordinary circuit gates.

## Primary contracts and selected mechanism

[Ambainis, arXiv:quant-ph/0311001v9, Sections 2 and 6](https://arxiv.org/pdf/quant-ph/0311001v9) gives element-distinctness query bounds and an implementation using history-independent data structures. Its time model explicitly includes random-access quantum-memory swap gates. [Tani, arXiv:0708.2584, introduction and claw-finding construction](https://arxiv.org/pdf/0708.2584) gives equal-domain claw search with O(N^(2/3)) queries, including an arbitrary fixed two-output relation extension. Thus a weighted threshold is not inherently outside quantum query search. The time cost of evaluating and maintaining that relation must still be supplied. [Magniez-Nayak-Roland-Santha, Theorem 3](https://arxiv.org/pdf/quant-ph/0608026) separates setup S, update U and marked checking C: S+epsilon_mark^(-1/2)(gap^(-1/2)U+C).

The selected construction is an explicit half decoder followed by a polynomial-size dyadic expansion of the price threshold into ordinary colored equality. This avoids assuming a specialized dynamic minimum-price oracle inside the walk. It does not assert a new claw algorithm or a new interference principle.

## Explicit finite generation domain

Use S3073 parameters h=floor(k/2), r=3 ceil(log2 k)+3, and D=max(1,3(Delta-1)); assume M>=1 and k>=2, with trivial empty cases handled separately. Construct the clause-intersection adjacency lists classically in polynomial input time, with neighbors ordered by original clause ID and padded to D slots. This table is polynomial in the original input, not the exponentially large half list. Even scanning the whole adjacency table for a coherent lookup therefore costs polynomial original-input gates.

A fixed-length index contains: a plane rooted forest shape with at most h vertices and at most r components; up to r original-clause root IDs; and h padded neighbor-slot choices. The shape may be encoded as a balanced-parenthesis string of length 2h with an explicit active length and component boundaries; malformed shapes are invalid. Root slots and unused neighbor choices are padded. There are at most poly(h,r) 2^(O(h)) M^r D^h encodings. Rounding each field to a binary power only changes the 2^(O(h)) and polynomial factors, because there are r root fields and h neighbor fields. Let N be this explicitly padded power-of-two domain size.

Decode a shape depth first. Map each root to its root ID; map each child to the selected neighbor of its parent's clause. Reject a missing slot or repeated clause ID within a component. Components may overlap each other: take their union and reject an empty result or support larger than h. Repeated union descriptions are retained, not silently deduplicated. A connected set has a rooted ordered spanning tree, so every union required by S3073 has an encoding. Hence all short odd minimal circuits retain their two represented halves. No unknown witness tree is supplied free.

All index fields have polynomial length in n,M,k. A deterministic decoder runs in polynomial original-input time and space by fixed bounded loops, adjacency scans, sorting at most h IDs, and exact XOR/sign arithmetic. Retain the index and reverse temporary computation to implement the value oracle |i,z> -> |i,z XOR value(i)> with polynomial gates and workspace. This oracle is many-to-one in its value but reversible because it retains i. It needs no coherent lookup into a precomputed N-entry list. Uniform superposition over the padded domain uses its binary index register; invalid states do not need rejection preparation.

## Turning a price threshold into a genuine claw

For one nonnegative rational price query, scale to common-denominator nonnegative integers. S3073's multiplicative weights already has such an integer representation. Let K=h times the largest integer clause price, choose b>=1 with 2^b>K, and test whether a pair of valid halves with equal syndrome, opposite sign and summed price at most T exists. Here 0<=T<=2K. Since each half has size at most h, every pair has combined size at most k; exact cardinalities are retained for verification but need no extra threshold filter in this final balanced-half version.

The left domain keeps only sign-zero halves U. For price a=p(U), decompose [0,min(K,T-a)] into disjoint dyadic intervals; if T-a<0 there are none. A dyadic interval is represented by its binary prefix and prefix length in the b-bit universe. This initial interval has at most b+1 canonical blocks, computable in polynomial b time. Add a block-index field and emit key (syndrome(U),prefix length,prefix value).

The right domain keeps only sign-one halves V. For price c=p(V), add a field selecting one of its b+1 binary prefixes, including the empty prefix, and emit the same kind of key. All genuine keys have a valid tag; invalid halves or unused block slots emit two distinct invalid tags, one per side and both different from the valid tag. Thus they never form a cross-domain claw. Pad each domain to the same power-of-two size N'=N poly(b). A key match exists exactly when the right price belongs to the left interval, equivalently a+c<=T, with the required syndrome and signs. Every emitted key has polynomial bit length and a polynomial-gate decoder. There is no expansion over all possible numerical prices.

A returned pair decodes to S=U symmetric-difference V. Verify its original IDs, nonempty odd sign, zero incidence, size<=k and nonnegative price bound exactly. By S3073 coverage, the minimum achievable pair-sum equals the minimum short-odd-tuple price: a cheapest tuple contains an odd minimal circuit with represented disjoint halves, and every pair produces a valid tuple of price no larger than its sum. This statement concerns the optimum; an arbitrary threshold output need not itself have minimum price unless the optimal threshold was found.

## Query guarantee and amplified classical wrapper

Binary search integer thresholds in [0,2K], first checking the upper endpoint, and finally extract a pair at the least successful threshold. Use a bounded-error claw finder amplified for every call. At most O(b) calls suffice, each with O((N')^(2/3)) queries up to amplification factors. On the event that all calls are correct, this is the exact price oracle required by S3073. If no pair is returned, the refutation procedure reports no certificate; it does not certify absence of short tuples from a failed quantum search.

For J polynomially many multiplicative-weights rounds, allocate failure probability delta divided by an upper bound on the total threshold calls. Price bit lengths and J are polynomial in original input and inverse packing accuracy. Conditional on any prior classical history, a fixed query has the same worst-case bounded-error guarantee, so a union bound works for adaptive prices without fresh input or sign assumptions. Overall decoder-query count is N^(2/3) times polynomial(n,M,k,epsilon^(-1),bitlength(epsilon),log(1/delta)). Repeated price changes require fresh query circuits and walk setup, both charged within those factors. The retained classical output consists of polynomially many indices and original-clause tuples. Extracting a claw from a found marked subset may scan its r_w stored records; this is charged in the setup-scale cost below, rather than assumed to be polynomial original-input readout.

Final parity, clause-load, mass and directed spectral checks remain classical and exact as in S3073. Therefore false search results cannot yield a false refutation. The success and approximation guarantees hold with the declared failure probability; pointwise refutation soundness does not rely on accepting an unverified quantum optimality assertion.

## Where time and memory differ from queries

For completeness, combine the two expanded domains, retaining a side bit, and mark an r_w-subset if it contains opposite-side equal keys. Sort its records by (key,side,index). A colored equality exists iff some adjacent pair has the same key and opposite sides. Inserting or deleting one record changes only constantly many such adjacencies. Thus a generic history-independent ordered data structure can maintain the marked counter with the same local operations; no numerical min-tree is needed. The implementation justification below uses a generic fixed-subset guarantee rather than the special collision/symmetry analysis of the original element-distinctness implementation. The index, rather than the decoded half, makes records distinct despite duplicate encodings.

The generic source is [Akmal-Jin, Near-Optimal Quantum Algorithms for String Problems, Algorithmica 2023, Section 2.3 and Lemmas 3.13-3.14](https://link.springer.com/article/10.1007/s00453-022-01092-x). It explicitly uses quantum random-access gates. Its history-independent hash table has a no-overflow guarantee for any fixed set of at most r_w distinct keys; its dynamic arrays/skip lists support indexing, insertion and deletion with high-probability polylogarithmic work. Use distinct encoding indices as keys, and keep their records in the exact (value,side,index) order. Dynamic-array indexing plus binary search locates an insertion position in polylogarithmic operations. Maintaining the adjacent-pair counter adds only constant local changes. Fixed-seed representations and counters depend on the current subset and its order, not update history.

The randomized data structure needs an explicit coherent error argument. For each separate quantum search invocation, choose a fresh seed independently of its now-fixed classical input, prices and threshold. Consider the ideal logical subset-walk states; their amplitudes do not depend on this seed. For any fixed logical subset, queried index and operation, increase bucket capacities, independence and skip-list cutoffs so that the probability of overflow or exceeding the fixed runtime budget is at most p_bad. These parameters are polynomial in log(N' T/ rho), where T bounds the number of data-structure operations in that invocation and rho is its allocated error. The source's arbitrary inverse-polynomial failure guarantee is used with these enlarged parameters; no single seed is asserted good for all exponentially many subsets.

For precision, compare exact canonical encodings of each ideal logical state with a fixed-time reversible implementation. Keep operation clocks and failure flags coherently, and uncompute workspace; do not measure or discard the slow branches. On good operation inputs it agrees with the ideal operation. Orthogonality of different logical indices implies that, averaged over the seed, the squared norm of a bad-input component is at most p_bad, even when the subset is in superposition. A hybrid comparison at T operation boundaries therefore has expected state-vector error at most 2T sqrt(p_bad). Choosing p_bad<=(rho/(8T))^2 makes this error a controlled fraction of rho. This argument compares to seed-independent ideal logical amplitudes; it does not falsely assume that the actual faulty trajectory stays independent of the seed. Fresh seeds for later adaptive classical calls allow the same conditional error accounting. All larger cutoffs and seed lengths enter polynomial logarithmic factors. This closes the fast-update justification in the declared random-access-gate model only.

In the augmented quantum random-access-gate model, the known ordered structure gives polynomial-logarithmic update/check work, multiplied by polynomial record-bit and decoder cost. Uniform subset setup costs r_w times those factors. If a claw exists, a uniform subset contains a fixed claw with probability Omega((r_w/N')^2). The lazy Johnson walk has spectral gap Theta(1/r_w). Substitution into the charged search formula gives r_w+N'/sqrt(r_w), times polynomial factors. With r_w=Theta((N')^(2/3)), augmented-model time and coherent record memory are (N')^(2/3) times polynomial factors. The memory is newly built from oracle calls; it is not a supplied half-list table. It is nevertheless exponentially large in the FKO parameter, and its addressed quantum swap gates are an explicit additional resource assumption.

This is NOT yet an ordinary bounded-fan-in circuit gate speedup. Replacing each addressed memory operation by a direct multiplexed scan of r_w records costs O(r_w) times polynomial record/address bits. At r_w=Theta((N')^(2/3)), directly replacing the addressed operations in this implementation yields the conservative ordinary-gate upper bound (N')^(4/3) times polynomial factors, including memory initialization and output extraction. More generally the scan simulation is bounded by (r_w^2+N' sqrt(r_w)) times polynomial factors. Taking constant r_w supplies no improved domain exponent over the classical N scale. These are upper bounds for these implementations, not gate lower bounds. No lower bound for every possible circuit implementation follows. A demonstrated inexpensive coherent data structure in the intended gate model, or another lower-memory search algorithm with a better total bound, is the unresolved access obligation. Calling an N-entry list oracle easy does not discharge it.

## Scope and status

At the FKO scale, log N <= (1/5)k log n+O(k)+O((log n)^2). Hence the query bound, and separately the augmented random-access-gate time bound, have upper leading term (2/15)k log n with the same lower-order types. This is conditional on the stated access model for time, not a physical speedup, fastest-known claim or general SAT result. The ordinary-circuit outcome currently establishes a polynomial decoder and the query reduction, but not improved total gate complexity. The original random robust-witness theorem and exact verification can supply probabilistic refutation success only after respecting that distinction.
