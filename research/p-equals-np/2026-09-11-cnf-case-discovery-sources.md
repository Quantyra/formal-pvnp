# CNF case discovery: focused source comparison

Date: 2026-09-11. S3059, E004/S008. Independent source/adversarial audit under README and INTEGRITY-CLAIMS. No implementation, experiment, publication or general SAT claim.

## Existing mechanisms and exact limits

**Williams, Gomes and Selman, [Backdoors To Typical Case Complexity](https://www.ijcai.org/Proceedings/03/Papers/168.pdf), IJCAI 2003.** Definition 2.4 requires every assignment to a strong backdoor to yield an instance decided by the specified subsolver. Section 4.1, Algorithm 4.1, already searches increasing sizes of variable subsets and runs the subsolver on assignments. Thus deterministic enumeration of small supports is an established method. A support whose cases merely return sound partial information is not thereby a strong backdoor. The source's heuristic-selection results assume an effective selection advantage; they do not provide one for arbitrary input CNF. The equations in the extracted PDF text are incomplete, so no numerical exponent from its later theorems is imported here.

**Gwynne and Kullmann, [Generalising unit-refutation completeness and SLUR via nested input resolution, arXiv:1204.6529v5](https://arxiv.org/pdf/1204.6529v5).** Definition 4.3, printed pp. 16–17, defines recursive failed-literal reductions r_k: r_1 is unit propagation, r_2 is full failed-literal elimination. For k>=1 the cited bound is O(length(F)*n(F)^(2(k-1))). Section 4.3 connects these reductions to nested input resolution. Theorem 7.4 gives SLUR_k=UC_k; Theorem 7.5 makes recognition coNP-complete for fixed k>=1. These are precise results for that hierarchy, not a theorem identifying the present Gaussian/common-consequence learner with r_k. In particular, a counterexample to one does not automatically transfer to the other.

**Andraschko, Danner and Kreuzer, [SAT Solving Using XOR-OR-AND Normal Forms](https://doi.org/10.1007/s11786-024-00594-x), 2024.** As checked in [S3058's source note](2026-09-11-global-parity-learning-sources.md), Proposition 4.10(c) and Example 4.11 already obtain shared affine information by intersecting consequence spaces for complementary cases. Starting with ordinary CNF changes the discovery/input requirement, not the soundness principle of this join. Recovering a useful affine representation or choosing cases requires separate effective rules.

Access scope: the cited primary definitions, algorithms and relevant theorem statements were read; the earlier S3058 full-text check is reused for the final source. This is a focused mechanism comparison, not an exhaustive priority review. The SLUR source is pinned to its arXiv v5 despite an internal 2018 manuscript date. No claim of a newly discovered inference principle follows from these sources.

## Selected policy and independently checked family distinction

The author selected ordinary CNF input with no initial affine equations and no guard annotations. Increase the support budget r from 0 to W; at each level enumerate all subsets of the original variables of size at most r and all their assignments. Each case runs global unit propagation plus Gaussian propagation from equations already learned. Failed cases add their blocking clauses; consistent case summaries contribute common augmented affine equations through intersection. Saturate before increasing r. This is a concrete deterministic bounded-lookahead learner, not a claim to have invented exhaustive lookahead or the common-consequence operation.

On the explicit degree-three Tseitin CNF family, assigning two incident edge variables makes the third a unit consequence of the four-clause local parity encoding. Every consistent case on this pair therefore implies the original vertex parity. Intersecting the case equation spaces recovers that parity without a supplied XOR annotation; if every case conflicts, refutation is already justified. Recovering all vertex equations lets Gaussian elimination refute odd total charge. This positive check identifies a particular useful support size, not a general CNF-to-XOR recognizer.

For the author's functional pigeonhole CNF with n+1 pigeons and n holes, take n>=W+2. A consistent assignment on at most W cells has its true cells forming a partial matching. Unit propagation forces incompatible cells false but cannot force a new positive cell: each unoccupied pigeon row retains at least n-W>=2 possible holes. A contradictory case already contains two true cells prohibited by an input at-most-one clause. Its learned blocking clause weakens that clause and adds no stronger unit-propagation effect.

For a fixed probed support, the union of the consistent cases' affine-summary solution sets contains the all-zero vector and every coordinate unit vector. Choose the all-false support assignment for zero; for unit vector e_v, assign v true if it belongs to the support and otherwise assign the support false. These vectors satisfy the corresponding affine summaries, consisting only of assumed values and forced negatives. They are **not** asserted to satisfy the pigeonhole CNF or its case residuals. Their differences span all coordinate directions, so no nonzero augmented affine equation is common to all cases. The learned affine space remains empty. The weakening clauses cannot change this argument on later sweeps.

Consequently the specified learner reaches an unresolved fixed point at each budget through W although the family is UNSAT. This is a uniform obstruction over every selected support in the budget, not a bad-ordering example. It does not lower-bound all recursive failed-literal procedures, resolution, backdoor algorithms, affine reasoning or unrestricted SAT algorithms. The exact relation to the r_k hierarchy above has not been established; do not transfer its proof-complexity theorems to this learner.

The operation is known in its main ingredients; originality of the precise family/policy formulation is unverified. The result supports the bounded mathematical attempt and identifies lost non-affine information. It does not supply a publication or general complexity claim.

## Costs and misleading shortcuts to exclude

For n original variables and maximum support size k, an exhaustive policy examines up to `sum_{j=0}^k binomial(n,j)*2^j` assignment cases in each complete sweep. Fixed k makes this polynomial, but growing k does not retain a uniform polynomial bound by the same argument. A supplied logarithmic-size support has only polynomially many assignments, whereas enumerating all such supports generally has a much larger bound. These are different costs.

All failed supports, scans with no progress, local extraction attempts and repeated case closures belong in the work accounting. Gaussian row-rank progress bounds the number of independent learned equations, not the total number of attempted supports. If learned nogoods or support candidates expand, their full finite universe or another progress bound must be specified. Arbitrary hidden parity recognition and a minimal useful support are not free preprocessing steps.

Input encodings matter. A parity equation supplied natively and an arbitrary CNF encoding of the same relation can have very different extraction/propagation behavior. Recovered equations need a checked implication or equivalence justification; replacing a nonlinear residual by its affine hull without retaining that residual is unsound. Fresh variables used by a family constructor remain ordinary input variables for an unannotated solver: constructor knowledge is not an available support-selection oracle.
