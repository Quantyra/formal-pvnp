## Preserve the actual proof-table identity

Hastad's SWP has one table A_V for each variable SET V (author-version Section3, printed p21; local text916-929). A_U and the conditioned A_W are accesses to this family. The address must therefore be `(sorted variable labels V, full truth vector on assignments to V)`. Do NOT add a left/right tag, clause-tuple key or conditioning-predicate key. In particular U=W can produce identical addresses; different h on the same W must share underlying proof bits. Making a table per h would change the soundness problem.

Use input `Literal := Nat * Bool`, where the Bool is negation, `Clause := Literal * (Literal * Literal)`, and `CNF := List Clause`. Derive all views from the actual ordered tuple of selected clause-position occurrences; no supplied restriction-map or conditioning-law fields. Clause occurrence identity and literal position survive repetitions. For a question q in `(Fin m * Fin 3)^u`, derive U by sorted deduplication of selected labels and W by sorted deduplication of all selected-clause labels. Derive restriction from W assignments to U by actual label lookup. Evaluate the selected clause conjunction h on W assignments. Lexicographic assignment enumeration is fixed and includes the sole empty assignment when V is empty.

## First bounded module contract

For sorted V, represent a truth vector as `Fin (2^V.length) -> Bool`, where bit b represents sign (-1)^b. `SignedAddress := Address * Bool`; evaluation is `proof(address) xor sign`. Implement the raw address injection, not an assumed indexing oracle: serialize `(V, List.ofFn vector)` with existing DataEncode, then encode the resulting word injectively into Nat by `wordNat []=1`, `wordNat (b::s)=2*wordNat s + bit(b)`. Prove injection (parity and division by2), hence no address collisions except genuine equal V/vector. Binary length is word length plus1; no unary expansion of arbitrary source labels is permitted.

`foldQuery V sat f : Option SignedAddress` must enumerate the actual satisfying assignment indices. If nonempty, take its first index y0, let sign=f(y0), and use the FULL V-vector `canon(y) := if sat(y) then f(y) xor sign else false`. If empty, return none. A-query uses sat identically true; B-query uses actual h. The rendered primary source uses sign -1 for logical true and +1 for false: `sat=true` means h=-1, whereas the off-domain default bitfalse=0 means sign+1. Thus this default implements the literal conditioned function, not an alternate convention. Canonicalization is the same selection of a conditioned complement pair for every query on V: value at first satisfying point is false, outside-domain coordinates are fixed false. It queries the underlying A_V at this full vector, not a new table on a smaller domain.

Prove from these definitions: dependence only on the restricted truth vector; complement queries have the same address and opposite sign when the domain is nonempty; honest evaluation at any satisfying y is f(y). The latter uses the explicit honest proof mapping `(V,c)` to c evaluated at the restriction of a global satisfying assignment. Do not assert odd folding on an empty domain: constant conditioned functions cannot also be odd. Returning none is meaningful and necessary.

For a selected view and f,g,noise, form `g2(y)=f(restrict y) xor g(y) xor noise(y)`. Return a concrete ordered row `(addrA,(addrB1,addrB2))` with RHS `signA xor signB1 xor signB2` when all accesses succeed. Prove that the actual three queried proof bits have even parity iff this emitted equation holds. Keep repeated addresses as THREE summands, even if cancellation is possible algebraically. Bridge to ZMod2 using the accepted concrete Bool/ZMod2 roundtrip, so the theorem identifies the actual `ActualSourceNormalization.rowValue/rhsValue` predicate rather than defining a second unrelated notion of satisfaction.

This first pair requires only finite tables, explicit Boolean algebra, injection and list indexing. Checks: singleton satisfying domain, complement queries, repeated U/W labels, U=W without namespace separation, identical second/third addresses, nonzero RHS, empty conditioning, and both RHS Bool values. No Fourier lemma or soundness premise belongs in this pair.

## Exact dyadic enumeration, immediately next

Fix parameters u>=1 and b>=2 outside the varying input. Set epsilon=2^(-b), F=2^u, G=2^(3u), and K=F+(b+1)*G. A random tape has exactly K bits: F for padded f, G for padded g, and b bits for each of G noise coordinates. For each actual assignment use the corresponding initial coordinate of its pad; discard unused coordinates. Noise bit is true exactly when its b-bit block is all false. Exactly one of2^b blocks produces a negative sign, so noise is independent with the required epsilon. Do not use a finite approximate inverse-CDF sampler here.

Use the concrete ordered list of ALL outcomes `q in (Fin m * Fin3)^u` and tapes in `Fin K -> Bool`, obtained from explicit list enumeration in lexicographic order. Prove Nodup of OUTCOME INDICES and exhaustive coverage, not Nodup of emitted rows. For the normal branch the list length is exactly `Q=(3*m)^u * 2^K`. Each outcome contributes one row, without sorting or deduplicating equations. Prove the fair-tape projection fibres have their actual power-of-two sizes, giving uniform f/g and independent dyadic noise despite different |U|,|W|. Then prove exact integer equality between satisfying row occurrences and accepting experiment outcomes for every proof assignment. Division by Q is only a subsequent corollary with m>0; arbitrary clause selection is uniform over (3m)^u outcomes, not necessarily a fair-bit sampler unless its denominator is a power of two.

Exceptional branches are GLOBAL. First scan every clause tuple for an empty h-domain, exhaustively checking at most2^(3u) assignments per tuple. If any is empty, return a fixed NO source; prove the witness tuple contradicts any satisfying assignment of the full formula. Do not replace just that tuple's rows and still claim the normal experiment equality. A concrete NO source is `([(0,(0,0)),(0,(0,0))],[false,true])`, value exactly1/2; repeated labels are legal before accepted regularization. If m=0, return fixed YES `([(0,(0,0))],[false])`, which has a satisfying assignment. Define the normal Q/equality theorem only on the nonempty, no-empty-domain branch. This also avoids a false positive-denominator claim for an empty source.

## Actual output and encoding boundary

Return the existing `ActualSourceNormalization.Source := List (Nat * (Nat * Nat)) * List Bool`. Define each row/RHS together and then unzip so `Valid` (equal list lengths) is proved. `encodedSource phi := ActualSourceNormalization.wire (emitSource phi)` is a TOTAL encoding of structured CNFs, including both exceptional branches. It connects directly to accepted normalization, WireBridge and original-row APIs; do not restore Instance.distinct or introduce a distinct-source-triple premise. Accepted generalized occurrence allocation supplies distinct OUTPUT ports for repeated source addresses.

An arbitrary raw-word FP map is a separate concrete follow-on, not justified by `encodedSource` being defined. DataEncode.lean supplies encoding/injection, not a generic decoding FP theorem. The raw implementation must actually validate the chosen nested clause encoding, define malformed input to return the fixed NO word, and implement question/tape loops with existing Materialize/listEncFn and derived input clocks. Prove equality to this exact emitSource on canonical CNF wires and FP for the SAME raw function. No externally supplied clock, decoder correctness or runtime field. The normal branch has polynomially many outcomes only for fixed u,b; K and its exponential are constants depending on them. Sorting/lookup/conditioning inspect at most3u labels and2^(3u) assignments per question, while labels are compared/encoded in their input binary width. This is an algorithmic plan, not a proved FP bound. A formal cost/size proof and malformed-wire scanner are still required.
