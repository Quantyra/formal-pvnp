# Global parity learning: source comparison

Date: 2026-09-11. S3058, E004/S008. Independent source audit under README/INTEGRITY-CLAIMS. No simulation, solver implementation, new general SAT claim, or publication claim.

## Exact source boundary

**Beame and Sun, [Extending CDCL to Disjunctions of Parity Equations](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SAT.2026.5), SAT 2026.** Proceedings Theorem 4.10, p. 5:12, starts with a Res(parity) refutation using M additions and proves existence of decisions and restarts yielding at most 2n^2 M learned clauses. Its proof selects an asserting-like decomposition using the supplied refutation (Proposition 4.8), then absorbs it (4.9). The conversion is not an algorithm that discovers a short refutation from arbitrary input. Section 5 describes implementation heuristics separately. The [extended-version history](https://arxiv.org/abs/2605.15002) lists only v1 as of this audit; theorem numbering here refers to the published proceedings, not the extended PDF.

**Laitinen, Junttila and Niemela, [Extending Clause Learning SAT Solvers with Complete Parity Reasoning, v2](https://arxiv.org/pdf/1207.0988v2).** Section II, p. 2, specifies the XOR-module interface: conflicts and implied literals under assumptions return clausal explanations. Section III.B.4, p. 4, gives explanations from tableau equations. Thus deriving Boolean consequences from a Gaussian conflict is established. Its setting separates CNF from an XOR module; this source alone does not establish a polynomial strategy for choosing all useful guarded subsystems of a general XNF formula.

**Nieuwenhuis, Oliveras and Tinelli, [Solving SAT and SAT Modulo Theories](https://homepage.cs.uiowa.edu/~tinelli/papers/NieOT-JACM-06.pdf), JACM 2006.** Author PDF Definition 3.2, p. 22, states T-Learn; Property 3.9, p. 25, learns a clause excluding an inconsistent subset of assumptions. Theorem 3.7 supplies termination conditions, not a polynomial bound on all learned clauses. A guarded Gaussian conflict certificate is an instance of this established explanation principle. The author manuscript's page numbers differ from final journal pagination.

Access scope: these specific full-text definitions, theorem statements and relevant proof passages were read. This is a targeted comparison, not an exhaustive priority search or re-verification of the complete source papers. No source theorem is treated as a deterministic polynomial-time general SAT result.

## Elementary provenance check for a guarded Gaussian rule

Suppose explicit input rows have the form `g_i => [a_i x=b_i]`, where each g_i is a specified conjunction of Boolean guard literals. A Gaussian row dependency indexed by J with XOR_i a_i=0 and XOR_i b_i=1 proves that the conjunction of all guards g_i, i in J, is impossible. Negating this conjunction yields a sound learned guard clause. For a common guard g this is simply NOT g. Contradictory guard conjunctions produce a tautological learned clause, not new information.

Track row provenance by bit vectors over the original row indices and XOR these during elimination. This supplies a checkable dependency without finding a minimal inconsistent core. Finding some dependency is enough for soundness; requiring a minimum core would be an extra algorithmic task. A deterministic pivot order makes an individual elimination reproducible but says nothing by itself about the total number of contexts selected by an outer learning policy.

## Selected policy and closest common-consequence precedent

The selected rule is stronger than common-guard inconsistency detection. Freeze the distinct original input guard supports T, each with at most w variables. In each sweep enumerate all complete assignments to each T; run global Boolean unit propagation and Gaussian closure on unconditional and activated rows. Record a nogood for each inconsistent case. Across the consistent cases for a support, intersect the row spaces of their augmented affine equations, retaining every common equation as a global consequence. Apply feedback simultaneously and repeat. The all-inconsistent case refutes directly; inconsistent cases impose no restriction on the common consequences of actual models.

**Andraschko, Danner and Kreuzer, [SAT Solving Using XOR-OR-AND Normal Forms](https://doi.org/10.1007/s11786-024-00594-x), 2024, Proposition 4.10(c)** explicitly learns linear consequences through intersection of the consequence spaces for complementary alternatives f and f+1. Example 4.11 derives x1+x2 and then reduces the representation by Gaussian propagation. This is a direct predecessor of affine information shared across cases. The selected policy uses explicit bounded guard supports and a different prescribed closure procedure; equivalence or strict superiority over their full solver has not been established. The generic intersection principle is not new.

The fixed-support restriction is essential for accounting. With q original supports there are at most q*2^w candidate case nogoods; independent consistent affine equations have rank at most n. Thus a sweep that adds neither a new nogood nor a new independent equation reaches the selected fixed point. This is a finite progress bound for this policy, provided canonicalization, each case closure, intersections and representation changes are charged. It is not a completeness theorem or a guarantee that the final residual is easy. Allowing unlimited new support generation would invalidate this particular counting argument.

## Selected nonlinear ring: independent mathematical check

For m>=3 and ell>=1, the author encodes z_i = (g_i AND h_i) in ordinary CNF and includes the unconditional parity XOR_i z_i=1. Each of the four explicit assignments (g_i,h_i)=(alpha,beta) activates its own length-ell parity path from x_i to x_(i+1), with cyclic indices and fresh internal variables for each path. The first edge has charge alpha*beta and the remaining edges have charge zero. The product here is Boolean AND, not field addition. The original single-edge version is ell=1.

In each case for support {g_i,h_i}, Boolean propagation fixes z_i=alpha*beta. Gaussian elimination sums the activated path equations, cancelling all internal variables and deriving x_i XOR x_(i+1)=alpha*beta. Combining this with the equation for z_i gives `x_i XOR x_(i+1) XOR z_i=0`, independently of the chosen case. This equation therefore belongs to the intersection of all four case consequence spaces despite their different internal variables. Gathering these m global equations and XORing cancels every x coordinate, yielding XOR_i z_i=0, contrary to the unconditional parity.

Individual case checks can remain consistent: only one path between consecutive ring endpoints is activated, the other paths' internal variables are free in this case closure, and the other z coordinates can satisfy the global odd parity. Hence conflict-only learning on these specified supports need not learn anything, while common-equation feedback does. The path length contributes explicitly to input size and Gaussian work; replacing an edge by a path does not confer a new complexity separation. This is an exact separation from that specified weaker policy, not from all failed-literal procedures, XNF solvers or CDCL(parity). Different chosen supports or stronger propagation can alter the comparison. The separate guarded odd-Tseitin example tests ordinary nogood learning rather than this common-equation step.

## Earlier candidate restriction that would make learning unnecessary

If the guard formula is Horn and all activations are conjunctions of positive guard variables, let h be its least satisfying assignment. Every other guard model activates a superset of the systems activated by h. Consequently one Gaussian consistency test of all rows activated by h decides the whole instance: consistency gives a witness at h; inconsistency persists for every guard model. Shared inner variables do not invalidate this argument. The Horn-unsatisfiable case terminates before Gaussian elimination.

This elementary check was sent to the author before selection. Such a family may demonstrate correct conditional reasoning, but cannot establish that learned guard clauses are needed. Conversely, allowing arbitrary outer CNF retains ordinary SAT as the case with no effective parity constraints. A polynomial result must retain its exact outer-language and activation assumptions.
