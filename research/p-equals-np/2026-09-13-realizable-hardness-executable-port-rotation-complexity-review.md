## Representation and graph scope

The input encodes n, vertex v, port j and dart label i in unary using nested pairs; the inner pair has length 2*v+2+j, the output pair has length 4*v+2*j+i+6, and its total input length is 2*n+4*v+2*j+i+8. For valid darts v<n, j<D and i<3 with fixed D, this is O(n+1). The output uses the corresponding unary vertex/port/label pair. FP is measured in this actual string length and is polynomial in numeric n. No polynomial-in-log(n) theorem follows. This is appropriate for a later explicit graph with O(n) vertices only after the source reduction proves that n and the serialized graph size are polynomially bounded in its source input length.

All-input FP applies to the total projection/length interpretation on arbitrary strings. It does not certify canonical pair framing or all-true unary words. Numeric invalid-input theorems address canonical input n v j i encodings: v>=n, j>=D or i>=3 return empty. Malformed raw strings may acquire a different numeric interpretation. That is a legitimate total extension for FP, but cannot be advertised as blanket malformed-syntax rejection.

At n=0 there are no valid v:Fin n; the separate zero-size theorem returns empty on canonical requests. For positive n the valid-dart domain is nonempty. Agreement is consequently not vacuous in the intended family.
